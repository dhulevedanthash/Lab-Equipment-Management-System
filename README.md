# Lab Equipment Management System

## Project Overview
A database management system developed using MySQL to manage laboratory equipment, student details, and equipment issue and return records.

## Technologies Used
- MySQL
- SQL

## Features
- Store and manage equipment details
- Maintain student records
- Record equipment issue details
- Track equipment returns and availability

## How to Run
1. Open MySQL Workbench or MySQL Command Line Client.
2. Open the `LabEquipmentDB.sql` file.
3. Execute the SQL statements in order.
4. Use the database queries to view and manage records.

SQL Mini Project
